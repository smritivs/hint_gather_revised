# HINT.GATHER Seed Genomes

- `default.json`: Default `chase` genome (`d=64, f=8, phq=32, L1D`), used for the gathers.
- `bfs_tuned.json`: BFS genome from the declared sweep (`d=2`, poll limit 64).
- `chase_l1d_aggressive.json`: Aggressive L1D `chase` seed.
- `chase_l2_conservative.json`: Conservative L2C `chase` seed.
- `value_poll_minimal.json`: Minimal `value` polling seed.
- `value_snoop_wide.json`: Wide `value` snoop seed.
